# App（PWA）重新安裝教學 — S7.3

> **對象**：全體隊員與志工。**一頁完成，約 5 分鐘。**
> 背景（R14）：平台網址更換後，舊網址安裝的 App、快取資料與離線地圖包
> **全部失效**——這不是壞掉，是網頁 App 的機制綁定網址。請照下面步驟重裝。
> 發布前由 owner 把 ⬜ 換成正式網址。

---

## 第 1 步：移除舊的 App

- **Android**：長按主畫面上的「光守隊」圖示 → 移除／解除安裝
- **iPhone**：長按主畫面上的「光守隊」圖示 → 移除 App → 從主畫面移除

## 第 2 步：用瀏覽器打開新網址

用手機瀏覽器（Android 用 **Chrome**、iPhone 用 **Safari**，別用 LINE 內建瀏覽器）打開：

> **https://⬜（正式網址）**

⚠ 如果是從 LINE 訊息點開的，請先點右下角「⋯」→「以預設瀏覽器開啟」再繼續。

## 第 3 步：加回主畫面

- **Android（Chrome）**：右上「⋮」→「加到主畫面」→ 安裝
- **iPhone（Safari）**：下方「分享」⬆ → 往下捲 →「加入主畫面」→ 新增

完成後主畫面會出現「光守隊」圖示，之後都從這個圖示開啟。

## 第 4 步：登入（或註冊）

舊平台的帳號**沒有轉移**。還沒有新帳號的夥伴先註冊，
註冊後通知你的組長開通權限，再登入。

## 第 5 步：離線整備（最重要的一步）

這一步決定**斷網、斷電時你的裝置還能不能作業**，請一定要做：

1. 開啟 App → 功能選單 →「**離線整備**」（網址列輸入 `/hub/offline` 也可以）
2. 依頁面指示完成**離線資料下載**與**離線地圖下載**（建議連 Wi-Fi 做，地圖包較大）
3. 確認頁面上的準備度檢查項目全部打勾

## 檢查：這樣就完成了

- [ ] 主畫面有新的「光守隊」圖示，點開不會跳出舊網址
- [ ] 已登入，看得到自己的姓名與角色
- [ ] 「離線整備」頁全部綠勾

## 常見問題

| 狀況 | 處理 |
|---|---|
| 找不到「加到主畫面」 | 確認用的是 Chrome（Android）／Safari（iPhone），不是 LINE 內建瀏覽器 |
| 開起來是舊畫面或空白 | 先把舊 App 移除（第 1 步），瀏覽器也清一次瀏覽資料再重來 |
| 登入說帳號不存在 | 舊帳號沒有轉移，要重新註冊 |
| 離線地圖下載很慢 | 換 Wi-Fi 環境下載；下載中請保持螢幕開啟 |
| 其他問題 | 洽你的組長，或聯絡：⬜（聯絡窗口） |
